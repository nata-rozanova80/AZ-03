# AZ-03
Scraping Divans - Analysis and Price Histogram
Описание программы
Этот скрипт использует библиотеку Selenium для автоматизированного сбора данных с сайта, а именно цен на диваны с конкретной страницы на сайте Divan.ru. Скрипт извлекает цены на продукты, записывает их в CSV файл и строит гистограмму распределения цен. Также вычисляется средняя цена на диваны, которая выводится в консоль.

Этапы работы программы:
С помощью Selenium открывается страница с товарами.
Извлекаются данные о ценах на диваны.
Записываются цены в CSV файл.
С использованием библиотеки pandas создается DataFrame, где происходит вычисление средней цены.
Построение гистограммы цен с использованием matplotlib.
Закрытие веб-браузера.
Требования
Для корректной работы программы необходимо установить следующие библиотеки:

Selenium - для автоматизированного взаимодействия с браузером.
pandas - для обработки данных.
matplotlib - для визуализации данных.
chromedriver - для работы с Chrome через Selenium.

Установка зависимостей:
Для начала работы с проектом установите необходимые библиотеки:

pip install selenium pandas matplotlib

Также скачайте chromedriver (для вашего браузера Chrome) и добавьте его в системный PATH.

Как использовать
Запустите скрипт. Он автоматически откроет браузер, перейдет по указанному URL, извлечет данные о ценах и сохранит их в CSV файл.

После завершения работы программы скрипт выведет среднюю цену на диваны в консоль и построит гистограмму цен.

Пример:

Средняя цена на диваны: 15000 ₽
Структура проекта:

Scraping_Divans/
├── divans.csv                 # CSV файл с извлеченными данными о ценах
├── divan_scraping.py          # Скрипт для сбора данных и построения гистограммы
Пример гистограммы
После выполнения скрипта, программа покажет гистограмму распределения цен на диваны. Гистограмма будет отображать частоту появления каждой ценовой категории в данных.
